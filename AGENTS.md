# Petunjuk Kerja Frontend

## Version Tagging

- Ikuti kebijakan **Frontend Version Tagging** di [README.md](README.md#frontend-version-tagging) setiap kali menyiapkan versi atau tag frontend.
- Tag pertama dimulai dari `v0.1.0` selama tahap development, lalu gunakan format `vMAJOR.MINOR.PATCH` berdasarkan versi terakhir.
- Gunakan annotated tag dengan description berbahasa Indonesia yang mencakup fitur frontend, perubahan UI/UX, perbaikan bug, dan peningkatan lainnya yang relevan.
- Perbarui `CHANGELOG.md` untuk setiap rilis: versi, tanggal, dan perubahan harus sesuai commit yang ditandai. Gunakan catatan rilis tersebut sebagai dasar description tag.
- Batasi description pada perubahan frontend yang sudah tersedia pada commit yang ditandai. Jangan menimpa tag yang sudah ada.
- Kebijakan ini merupakan preferensi proyek yang sudah ditetapkan; jangan meminta pengguna menjelaskannya ulang. Buat atau push tag sesuai permintaan pengguna.
